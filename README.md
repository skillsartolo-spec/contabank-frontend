# ContaBank — Frontend

Sistema contable bancario para Javier Mignani (Carmera / Jam&Jam / Javier PF).

## Deploy en Vercel

1. Subí esta carpeta a GitHub
2. Importá el repo en vercel.com
3. En "Environment Variables" agregá:
   - `PDF_SERVER_URL` = la URL de Railway (ej: https://contabank-pdf.up.railway.app)
4. Click en Deploy

## Deploy en Netlify

1. Subí esta carpeta a GitHub  
2. Importá el repo en netlify.com → "New site from Git"
3. En "Environment variables" agregá:
   - `PDF_SERVER_URL` = la URL de Railway
4. Click en Deploy
